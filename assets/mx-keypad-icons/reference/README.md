# Authoritative MX Creative icon crops

These seven 480 x 480 PNG files are the accepted visual source for the
fesReview MX Creative Console profile. They were extracted from the
operator-provided **MX Creative With Text** reference sheet.

The crop is entirely inside the keypad's cyan outline, so the display output
contains only the icon, text, and dark interior. The seven files are:

1. `play-pause.png`
2. `first-frame.png`
3. `last-frame.png`
4. `back-1s.png`
5. `forward-1s.png`
6. `screenshot.png`
7. `dictate.png`

The red-boundary review images are stored only in `previews/`; their red lines
are annotation and are not part of the display assets.

These raster crops are the source of truth for the current keypad profile.
The SVG files remain editable design explorations and history, not runtime
authority.
